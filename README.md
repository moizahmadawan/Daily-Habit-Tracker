# 🌿 Daily Companion — Daily Habit Tracker

### *Small steps. Better days. One habit at a time.*

Daily Companion is a clean, minimal habit-tracking web application designed to help you build better routines without overwhelming yourself. Track your daily goals, celebrate small wins, and make consistency part of your everyday life.

No complicated dashboards. No unnecessary pressure. Just you, your habits, and a fresh start every day.

---

## ✨ Features

- **📊 Daily Progress Tracking** — View your completed habits, total habits, and daily completion percentage.
- **➕ Create Your Own Habits** — Add personalized habits with simple validation.
- **✅ One-Click Completion** — Mark habits complete or undo them whenever needed.
- **🗑️ Flexible Habit Management** — Remove habits that no longer fit your routine.
- **💾 Automatic Local Saving** — Your habits and completion dates are saved in your browser using Local Storage.
- **📅 Date-Aware Tracking** — Completion status updates for each new calendar day.
- **🌱 Encouraging Feedback** — Get gentle messages that celebrate progress and encourage your next step.
- **🎨 Minimal User Interface** — A peaceful, distraction-free design focused on consistency.
- **⚡ Fast and Lightweight** — Built with modern React tooling for a smooth experience.

## 🚀 Getting Started

### Prerequisites

Make sure you have installed:

- [Node.js](https://nodejs.org/) — preferably an active LTS version
- npm — included with Node.js
- Git — optional, for cloning the repository

### 1. Clone the repository

```bash
git clone https://github.com/moizahmadawan/Daily-Habit-Tracker.git
```

### 2. Open the project folder

```bash
cd Daily-Habit-Tracker
```

### 3. Install dependencies

```bash
npm install
```

> Note: If you are using a source export that contains workspace-specific dependencies, use the repository's original package manager and workspace configuration.

### 4. Start the development server

```bash
npm run dev
```

Open the local URL displayed in your terminal, usually `http://localhost:5173`.

### 5. Build for production

```bash
npm run build
```

To preview the production build locally:

```bash
npm run serve
```

## 🧭 How to Use

1. Open Daily Companion in your browser.
2. Explore the starter habits or add a new habit of your own.
3. Check off each habit when you complete it.
4. Watch your daily progress percentage update automatically.
5. Remove habits that no longer match your goals.
6. Return tomorrow and take the next small step.

**A simple example routine:**

- Drink a glass of water 💧
- Take a 10-minute walk 🚶
- Read before bed 📚

Start small. Stay consistent. Let progress build naturally.

## 💾 How Your Data Works

Daily Companion stores habit information in your browser's Local Storage.

- Your habits remain available when you reopen the app in the same browser.
- Completion dates are stored with each habit to calculate daily progress.
- No backend database or account is required for the current implementation.
- Clearing browser storage or using a different browser or device may remove or leave behind your saved data.

This is a local-first application, so your habit data is not automatically synchronized between devices.
